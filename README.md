# ExRe-Recuros-Estudiantiles-Flutter
Proyecto realizado para la clase de programacion android, por Alejandro Del Llano Hernandez

## Requisitos

Para ejecutar el proyecto se necesita tener instalado:

- Flutter SDK
- Android Studio
- Android SDK
- Android SDK Platform Tools
- Android NDK `28.2.13676358`
- Java / OpenJDK

También se puede utilizar un dispositivo Android físico con la depuración USB activada o un emulador.

## Instalación y ejecución

Clonar o descargar el proyecto y acceder a su carpeta:


```bash
cd exre_app

Instalar las dependencias del proyecto:
flutter pub get

Verificar la configuración de Flutter:
flutter doctor

Comprobar que no existan errores en el proyecto:
flutter analyze

Para ejecutar la aplicación:
flutter run


Para generar la aplicación:
flutter build apk
```

El código principal se encuentra dentro de lib/:
- models/: modelos de datos.
- data/: recursos utilizados por la aplicación.
- screens/: pantallas principales.
- state/: gestión del estado de la aplicación.
- widgets/: componentes reutilizables.
- theme/: configuración visual.
- main.dart: punto de entrada de la aplicación.
